# CLAUDE.md

## Project
A static single-developer design portfolio for Aryan Swaroop (Brand Designer & Creative Lead) — 11 hand-coded HTML pages (home, about, real-estate, lifestyle, builds, tools, playground, changelog, 404, and 2 case studies), one minified global `style.css` + 8 scoped stylesheets, vanilla JS (GSAP/ScrollTrigger/Lenis vendored in `js/vendor/`, plus a zero-dependency ES-module endless-runner game), and one Vercel serverless function (`api/manifest.js`) using `@vercel/blob`. Deployed straight from the repo on Vercel with clean URLs (`https://www.aryanswaroop.com`); no build step.

## Conventions
- **Header & mobile menu are generated, never hand-edited.** Edit `scripts/build-nav.mjs` (the single source of truth for `HEADER_HTML` / `MOBILE_MENU_HTML`) and run `npm run build:nav`, which rewrites all 11 pages in `TARGETS`. After adding a page, add it to `TARGETS`. If a header/menu edit does not survive `build:nav`, it was made in the wrong place.
- **Footer is generated, never hand-edited.** `scripts/build-nav.mjs` exports `FOOTER_HTML` and `replaceFooter()` rewrites it into all 11 pages (single `foot-bottom` row everywhere, index/404 game-footer deduped via `removeGameFootBottom()`). Run `npm run build:nav` after footer edits — hand edits to footers will not survive.
- **Cache-busting:** every asset URL uses `?v=YYYYMMDD` (e.g. `style.css?v=20260801`); bump the date when the asset changes. Images are served `immutable` for 1 year, so changed images MUST get a new filename or a new `?v=`.
- **Images:** prefer AVIF → WebP → JPG `<picture>` triplets with `width`/`height` set and `loading="lazy" decoding="async"` (except hero/LCP images, which are eager). Each of the three files must exist in `images/`.
- **Path style:** extensionless URLs in the nav/sitemap (`/real-estate`) because Vercel `cleanUrls` is on; the local `server.py` will 404 them (expected). Root-absolute paths (`/images/...`) inside `build-nav.mjs` are mandatory.
- **JS layout:** page scripts are loaded with `defer`; the game is a module graph entered via `main.js` (`#game` on index + 404). Every animated component must respect `prefers-reduced-motion` and have a no-JS/static fallback.
- **A11y invariants:** exactly one `<h1>` per page, sequential heading levels, skip-link first, `:focus-visible` outlines, alt text on every `<img>`, buttons (`<button>`) vs links kept semantically correct, touch targets ≥44px on mobile (see `css/mobile-fixes.css`).
- **CSP is live (M6 closed):** `vercel.json` `/(.*)` headers enforce `default-src 'self'; script-src 'self' https://unpkg.com 'unsafe-hashes' '<onload-hash>'` + Google Fonts, paavani VR iframe, `object-src 'none'`. The only inline script is the font-preload `onload` handler (hash-pinned). Elfsight is intentionally NOT allowlisted (brahmi mobile widget is dead/out of scope). Before adding any third-party script, add its origin to the `script-src`/`connect-src`/`frame-src` allowlist and re-verify with the headless CDP pass.
- **Known issue to respect:** the mobile Brahmi flipbook is an unconfigured Elfsight widget and renders blank (`work/brahmi.html:314-315`); the working PageFlip book is `js/flipbook-desktop.js`, desktop-only ≥768px. Do not "fix" the mobile book by touching `work/brahmi.html` alone — the plan is `AUDIT/15_Priority_Fixes.md` item 1.
- **Audit docs:** `AUDIT/` (00–15 + FINAL_SCORECARD) is the current source of truth for findings; prior reports are `AUDIT_REPORT_2026-08-02.md`, `PRODUCTION_AUDIT_REPORT.md`. The 2026-08-03 remediation pass is documented in `REMEDIATION_REPORT_2026-08-03.md` (finding ID → commit map, CSP notes, skip list).
