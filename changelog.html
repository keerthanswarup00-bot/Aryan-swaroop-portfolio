Changelog

What's New

A chronological record of updates, new projects, and improvements to this portfolio.

2026-08-03 Major

Audit Remediation Pass

Full remediation pass across all 11 pages: footer now generated from build-nav.mjs (identical foot-bottom everywhere); sequential heading hierarchy on about/real-estate/builds; touch targets ≥44px and AA-contrast text in the mobile menu; Content-Security-Policy added via vercel.json; mega-menu keyboard/focus support; playground videos lazy-loaded with AVIF posters; right-sized mega-menu thumbnails; missing browserconfig favicon; token-gated manifest API; deleted 4 dead JS files and trimmed unused CSS; SEO titles/descriptions trimmed to SERP-safe lengths; robots.txt AI-crawler allowlist refreshed; package-lock pinned.

2026-07-27 Major

AI Metadata & SEO Overhaul

Added production-grade structured data (JSON-LD @graph), Speakable schema, expanded Person profile with nationality/credentials/InteractionCounter, SearchAction on WebSite, AI summary blocks on all pages, skip-to-content accessibility, enhanced Open Graph and Twitter Cards, and comprehensive llms.txt. Created security.txt, humans.txt, browserconfig.xml, sitemap-images.xml. Updated robots.txt with 15+ AI bot allowances.

2026-07-27 Major

Playground Page Launched

Added Playground page with 22 media items (11 WebP images, 10 compressed H.264 videos). Lightbox with video play/pause, IntersectionObserver for performance, body scroll lock. Total page weight ~5.5MB down from ~55MB originals.

2026-07-27 Feature

Premium Navigation Redesign

Desktop mega dropdown (Owen Hudock–matched), mobile menu overhaul with staggered fade-in, circular avatar, pulsing green "Open to work" badge, 3-part layout. All pages updated.

2026-07-25 Feature

Game Audio Toggle

Added chiptune audio loop using Web Audio API with localStorage persistence. Muted by default. Works on home, about, and 404 pages.

2026-07-25 Feature

Endless Runner Game

Custom modular auto-runner game built with Canvas API. "WELCOME TO BENGALURU" intro sequence, speed reduced 10% for accessibility. Present on home, about, and 404 pages.

2026-07-25 Enhancement

Site Launch & Core Pages

Initial launch with 7 pages: Home, Real Estate, Lifestyle, Builds, Tools, About, 404. Shared CSS/JS, custom cursor, scroll-reveal animations, stats rolling counter, favicon system, meta/OG/Twitter tags. Deployed on Vercel with clean URLs.
